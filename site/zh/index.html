    04 / 流水线

    四步，其中一步是「拒绝走捷径」。

    有意思的决定都在边缘上：一刀允许切在哪里、几段怎么拼起来、什么才算真的做完。

    1. 01

      拿来一份高光列表

      任何能给出时间区间的工具都能用：sliceapp 导出的文本、你自己的检测器，或者手敲的一份 txt。检测刻意放在流程之外。

      txt · json
    2. 02

      切在关键帧上，而不是毫秒上

      流拷贝是逐位精确的，HDR、10 位色深和旋转元数据都能留住；切点会对齐到最近的关键帧，所以整条流水线从不为了「更准」去重编码片段。

      -c copy
    3. 03

      一次成型地拼接

      回合先 trim 再 concat，合成一次编码。最顺手的那种 concat demuxer 写法实测会留下 1.01 秒的永久音画偏移和 HEVC 坏参考帧，所以这个工具拒绝它，并把问题报出来。

      trim → concat
    4. 04

      自检通过才算交付

      每个产物都要检查：解码零错误、起始偏移为零、音画时长一致、首尾不是黑帧、音频不是静音。任一项失败，命令就以非零退出码结束。

      manifest.json

    05 / 产物

    你会拿到什么。

    一次运行一个目录。没有藏起来的工程文件：成片、片段、角标图层和报告就摆在一起。

    • reel_labeled.mp4带角标的成片——你要上传的就是这个。
    • reel_plain.mp4同一版拼装，画面干净，留给你自己加字幕。
    • clips/一个回合一条无损切片，原始 HDR，方向已烧进画面。
    • labels/*.png透明角标图层，任何剪辑软件里都能复用。
    • highlights.normalized.json这次实际用到的片段清单。
    • manifest.json全部参数和每一项自检结果。
    manifest 就是契约：每个参数、每一项自检结果，机器可读。 非零退出码代表自检失败——脚本和 Agent 不用把视频看完，也能相信这次运行。
    解码零错误 起始偏移 音画时长一致 预期时长 首尾非黑帧 音频非静音

    06 / 安装

    一行命令安装。

    还没发布到 PyPI，直接从仓库装。ffmpeg 要自己在 PATH 里——工具不会偷偷替你打包 40 MB 的 ffmpeg。

    终端 — 安装 + 运行 
    # 先装 ffmpeg：brew install ffmpeg  ·  sudo apt install ffmpeg fonts-noto-cjk
pipx install git+https://github.com/bobobo2026/tennis-evolution

# 高光列表可以来自 sliceapp、你自己的检测器，或者手敲
tennis-evolution all IMG_5155.MOV --highlights highlights.txt --top 5 --place "你的球馆" --timezone Asia/Shanghai --outdir out

    需要 Python 3.11 以上和 ffmpeg/ffprobe，macOS 与 Linux 均可。源码、issue 和完整的流水线笔记在 GitHub。

    10 / 常见问题
    
            
    经常被问到的几个问题。
    
          
    
          
    下面是短答案。更长的推理——包括具体的 ffmpeg 参数和踩过的坑——都在仓库里。
    
        
    

        
    
          
    
            
              我需要自己做击球检测吗？
              
            
            
    不需要。任何能给出时间区间的列表都能直接用：sliceapp 导出的文本、你自己的检测器，或者手敲的一份 txt。检测刻意放在流程之外——一个只为某间球馆混响调过参的击球计数器，会让整条流水线变脆。
    
          
    

          
    
            
              支持 iPhone 拍的 HDR 视频吗？
              
            
            
    支持。无损切片会原样保留 HLG、10 位色深和旋转元数据，合集也保留 HLG 色彩标签和 10 位深度。Dolby Vision 的动态元数据 x265 写不回去，重编码时会丢；HDR10/HLG 基础层完好。
    
          
    

          
    
            
              只能在 macOS 上用吗？
              
            
            
    CLI 在 macOS 和 Linux 上都能跑，需要 ffmpeg 在 PATH 里、Python 3.11 以上。打包好的 Mac 应用在计划中，可以先去 GitHub 点个 Star。
    
          
    

          
    
            
              不安装能先看效果吗？
              
            
            
    这个页面上所有片段都是预渲染的，可以先看再决定。刻意不做在线生成：那意味着要把你一小时的录像传到别人的服务器上。
    
          
    

          
    
            
              跑一次要多久？
              
            
            
    47 分钟源片、5 个回合，在 M 系列 Mac 上大约 3 到 5 分钟，绝大部分时间花在那一次 x265 编码上。本机网页版会显示每个阶段的实时进度。
    
          
    

          
    
            
              收费吗？
              
            
            
    免费版不收钱：本机渲染、MCP server、全部自检都能用，每条合集最多 5 段、带一个小水印。Pro 是一次性 ¥138（$19）的许可证，解锁全部回合、去掉水印。支持微信、支付宝、银行卡、Apple Pay、Google Pay；许可证离线校验，不联网、不上报。
    
          
    

          
    
            
              能让 ChatGPT / Claude / Cursor 帮我剪网球集锦吗？
              
            
            
    能，通过 MCP。接入网球进化的 MCP server（Claude Code 一行命令，Claude Desktop、Cursor、Codex、Windsurf 贴一段 JSON），然后直接说「把 match.MOV 里最长的五个回合剪出来，角标写我们球馆的名字」。Agent 会依次调用 probe_video、rank_highlights、start_highlight_reel、get_job，并把自检结果告诉你。渲染仍然在你自己的电脑上。
    
          
    

          
    
            
              Pro 多了什么？是订阅吗？
              
            
            
    不是订阅。Pro 是一次性 ¥138 的离线许可证：所有回合（不止 5 段）、无水印、你的每台电脑都能用、0.x 版本内免费升级。用 tennis-evolution license activate KEY 激活，或让 Agent 调用 activate_license。
