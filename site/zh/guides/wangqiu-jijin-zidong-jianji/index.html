指南

把一小时的网球录像，自动剪成带拍数角标的集锦

手机靠在铁丝网上录了一整场，想把最精彩的几个回合挑出来发朋友圈或小红书？下面三步，在自己电脑上完成，素材不上传。

第一步：准备回合列表

需要每个回合的开始和结束时间，三种来源都行：

  • sliceapp 等击球检测工具导出的文本，例如 27:14 - 28:08 Long rally (40 hits)；
  • 自己整理的 JSON：{"segments":[{"start":"27:14","end":"28:08","hits":40}]}；
  • 手动拖进度条记下时间，拍数可不填。

第二步：安装（约 2 分钟）

brew install ffmpeg
pipx install git+https://github.com/bobobo2026/tennis-evolution

第三步：一条命令出片

tennis-evolution all IMG_5155.MOV --highlights highlights.txt \
  --top 5 --place "宁波 ECHO Tennis" --timezone Asia/Shanghai --outdir out

得到带角标合集 reel_labeled.mp4、无角标合集、每个回合的无损片段，以及记录全部自检结果的 manifest.json。

为什么画面不会发灰

iPhone 录的是 HEVC 10-bit HLG（常带杜比视界）。很多剪辑方式会转成 8-bit 或丢掉色彩标签，成片发灰。网球进化切片用关键帧对齐的 -c copy（比特级无损），合集只编码一次并透传 BT.2020/HLG 标签，竖屏方向直接烧进画面。

角标长什么样

左上：球馆名、该回合的真实钟点（录制时间 + 偏移）、片源时间点；右上：大号拍数。中文字体渲染正常，不依赖 ffmpeg 的 drawtext。

不想敲命令？

可以让 Claude、Cursor 等 AI Agent 直接帮你剪，见 用 AI Agent 剪网球集锦；也可以运行 tennis-evolution web --open 在本机网页里点选操作。
