指南

让 AI Agent 帮你剪网球集锦

网球进化把整条流水线做成了 MCP server：AI Agent 可以读素材、挑回合、渲染带角标的合集、检查结果，而视频始终留在你的电脑上。

Claude Code

claude mcp add tennis-evolution -- uvx tennis-evolution mcp

或者装插件（含 Skill）：/plugin marketplace add bobobo2026/tennis-evolution，再 /plugin install tennis-evolution@tennis-evolution。

Claude Desktop / Cursor / Windsurf / Codex

{
  "mcpServers": {
    "tennis-evolution": {
      "command": "uvx",
      "args": ["tennis-evolution", "mcp"]
    }
  }
}

运行 Agent 的电脑上需要装好 uv 和 ffmpeg。Claude Desktop 也可以不写 JSON：下载一键扩展 tennis-evolution.mcpb，双击打开即可。

怎么跟它说

  • 「把 ~/Movies/match.MOV 里最长的五个回合剪出来，角标写宁波 ECHO Tennis。」
  • 「这是 sliceapp 导出的列表，按打球顺序做一条合集。」
  • 「检查 out/reel_labeled.mp4 有没有音画不同步。」

Agent 能用的工具

  • probe_video：时长、HDR、旋转、音轨、录制时间
  • rank_highlights：解析回合列表、预览会保留哪些
  • start_highlight_reel / get_job：后台渲染并轮询，完成后返回 manifest
  • verify_video：解码、音画偏移、黑帧、静音检查
  • license_status / activate_license：免费版 / Pro

常见问题

Agent 自己会数拍吗？

不会。回合列表由你提供（sliceapp 导出、手记或其他检测器），Agent 和工具负责剪辑、角标和自检。

免费版能在 Agent 里用吗？

能。免费版每条合集最多 5 段、带小水印；需要更多时购买 Pro 并让 Agent 调用 activate_license。
